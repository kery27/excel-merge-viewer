# 폴더 찾아보기 — 기능 정의 (초안 · 2026-11-09)

> 시제품을 만들기 전에 정리한 기능 정의. **확정 아님** — "확인 필요"로 표시한 것은 친구(물류센터 운영) 대화나 실측으로 정한다.

## 1. 왜 만드나 — 실제로 들은 사례

물류센터를 운영하는 가르시아의 친구(2026-11-08, 가르시아가 전해 들음):

- **반품이 들어오면, 그 물건이 언제 나갔는지** 확인하려고 **최근 30일치 발주(출고) 이력 엑셀을 하나하나 뒤진다.**
- **업체(거래처) 정보 이력**도 같은 식으로 찾는다.
- 지금 방식: 원하는 키워드가 있으면, 정해 둔 폴더 범위 안에서 그 키워드가 든 파일을 찾고, 파일을 열어 일부를 확인한다.

여기서 나온 문제:

| 문제 | 지금 모아보기로는 |
|---|---|
| 엑셀이 날짜별·업체별로 흩어져 있다 | 파일을 골라 넣어야 함 |
| 파일마다 제목 줄(칸 구성)이 제각각이다 | 제목이 많이 다르면 빼 버림 |
| 쓰레기 줄·합계 줄·메모 탭이 섞여 있다 | 맞추라고 묻거나 빼 버림 |
| 키워드 하나로 **그 줄**을 바로 보고 싶다 | 합친 뒤에야 검색 가능 |

→ **데이터 정리를 강요하지 않고**, 폴더째 연결해 두면 키워드로 바로 그 줄을 보여 주는 기능이 필요하다.

## 2. 한 줄 정의

**"폴더를 한 번 연결해 두면, 키워드 하나로 그 안의 모든 엑셀에서 해당 줄을 찾아 날짜순으로 보여 준다. 제목 형식을 맞출 필요가 없다."**

지금의 "모아보기"(같은 구조끼리 합쳐 칸 조건으로 거르기)와 나란히 두는 두 번째 입구다. 찾은 뒤 같은 구조끼리는 모아보기로 넘긴다.

## 3. 쓰는 장면

**처음 한 번**
1. [폴더 연결] → 발주 엑셀이 쌓이는 폴더를 고른다(하위 폴더 포함 여부 선택).
2. 폴더 안 엑셀을 전부 읽는다(진행률 표시). 끝나면 "파일 312개 · 줄 48만 개 준비됨".

**그다음부터 (반품이 들어왔을 때)**
1. 화면을 연다 → 바뀐 파일만 다시 읽는다(몇 초). 새로 생긴·고친·지운 파일 개수를 알려 준다.
2. 검색창에 상품코드·송장번호·업체명 같은 키워드를 넣는다.
3. 결과: "일치하는 줄 7개 · 파일 3개". **날짜 칸이 있으면 날짜순**, 기간(최근 30일 등)으로 좁히기.
4. 줄을 누르면 그 줄 전체 + 출처(파일 경로 › 탭 · 엑셀 몇 행)와 [위치 복사].
5. 필요하면 [이 결과 모아보기]로 같은 구조 탭끼리 합쳐 칸 조건으로 더 거른다.

## 4. 기능 목록

### 시제품에 넣을 것 (필수)

| # | 기능 | 내용 |
|---|---|---|
| F1 | 폴더 연결 | 크롬·엣지의 폴더 고르기. xlsx·xlsm·xls·csv. `~$`로 시작하는 임시 파일·숨김 파일은 제외. 하위 폴더 포함은 선택 |
| F2 | 읽기(정리 강요 없음) | 탭마다 제목 줄을 자동으로 찾되(못 찾으면 첫 줄), **원래 제목 그대로** 저장. 탭끼리 맞추지 않음. 모든 칸을 검색용 글자로 |
| F3 | 바뀐 것만 다시 읽기 | 파일 경로·크기·수정 시각 비교. 새 파일·고친 파일만 다시 읽고, 지운 파일은 결과에서 뺌. 화면 열 때 자동 + [다시 확인] |
| F4 | 키워드 검색 | 띄어 쓴 낱말은 모두 포함(AND), 부분 일치, 대소문자 무시. 숫자는 `1,000`과 `1000`을 같게(확인 필요) |
| F5 | 결과 보기 | 파일·탭별로 묶어 **각자 제목 그대로** 표시. 날짜 칸을 알아볼 수 있으면 날짜순 정렬·기간 필터(최근 7·30·90일). 결과가 너무 많으면 앞 1만 줄만 보이고 안내 |
| F6 | 줄 상세·출처 | 파일 경로 › 탭 · 엑셀 행 번호, [위치 복사] |
| F7 | 못 읽은 파일 알림 | 암호 걸린 엑셀, 깨진 파일, 너무 큰 파일은 목록으로 알림(조용히 빠지지 않게) |

### 다음 단계 (반응 보고)

| # | 기능 | 메모 |
|---|---|---|
| N1 | **일괄 찾기** | 반품 목록 엑셀(코드 여러 개)을 넣으면 코드마다 최근 출고 줄을 한 표로. **친구에게 가장 먼저 확인할 것** — STRATEGY의 "맞추기"와 같은 성격(두 데이터 대조) |
| N2 | 찾은 결과 모아보기 | 같은 구조 탭끼리 지금 모아보기 화면으로 넘기기 |
| N3 | 찾을 칸 지정 | "송장번호 칸에서만" 찾기. 탭마다 칸 이름이 달라도(송장번호/운송장/송장No) 별칭으로 묶기 |
| N4 | 열려 있는 동안 변경 감지 | 최신 크롬의 폴더 변경 감지 기능(보조로만) |
| N5 | 공유 폴더(NAS)에서 여러 명 | 폴더 안 저장본을 여러 PC가 같이 쓰기 |
| N6 | 셀 색 | 지금 모아보기의 색 읽기 재사용 |

### 지금은 안 함

- 브라우저를 닫아 둔 동안의 감시(설치 프로그램이 필요 — "설치 없이"와 충돌)
- PDF·한글·워드 파일 검색
- 엑셀 고치기·쓰기
- 서버·클라우드 전송

## 5. 미리 읽은 내용(저장본)은 어디에

| 안 | 장점 | 단점 |
|---|---|---|
| **A. 그 폴더 안 숨김 파일** (예: `.엑셀모아보기.db`) — 추천 | 원본 옆이라 관리 쉬움, 폴더 권한을 그대로 따라감, 공유 폴더면 여러 명이 같이 | 폴더 **쓰기** 허용이 필요 |
| B. 이 브라우저 안 | 폴더 쓰기 허용이 필요 없음 | 예전에 "브라우저 자동 저장"을 기각한 이유 그대로(대용량에서 조용히 실패한 전례, 고객 데이터 사본이 브라우저에 남음) |

→ A를 기본으로 하고, 쓰기가 안 되면 B를 **물어보고** 쓴다(결정 필요).

## 6. 제약·전제 (지금 확인된 것)

- **크롬·엣지만.** 파이어폭스·사파리는 폴더 고르기 기능이 없다.
- 이 개발 환경의 크롬(153)에서 파일 더블클릭(file://)으로 연 화면에도 폴더 고르기·변경 감지·브라우저 저장 공간 기능이 있음을 확인함.
- "다음에 열 때 자동으로 다시 읽기"는 크롬의 **"방문할 때마다 허용"**이 필요하다. 파일 더블클릭 화면에서도 되는지는 **확인 필요** — 안 되면 웹 주소(홈페이지 체험판 등)로 열어야 한다.
- "브라우저를 켜자마자"가 아니라 **"이 화면을 열면"** 시작된다.
- 처음 전체 읽기 시간은 파일 수·크기에 따라 분 단위가 될 수 있다(**실측 필요**). 그다음은 바뀐 파일만.
- 옛 형식(.xls)은 색을 못 읽는다. 암호 걸린 엑셀은 못 읽는다.

## 7. 데이터·보안

- 데이터는 PC 밖으로 나가지 않는다(지금 원칙 그대로).
- 저장본 A는 원본 폴더의 권한을 따른다. 비밀번호를 거는 선택지는 지금 저장 기능 재사용.
- 브라우저 저장(B)을 쓰면 "이 PC 브라우저에 사본이 남는다"고 안내하고 [지우기]를 둔다.
- 테스트는 가짜 데이터로만. 친구의 실제 파일은 받지 않고, 친구 PC에서 직접 써 보게 한다.

## 8. 잘 됐다고 볼 기준 (친구 사례)

- 준비된 뒤, **상품코드·송장 하나로 출고 줄을 찾는 데 10초 안**(화면 열기·바뀐 파일 다시 읽기 포함).
- 형식이 다른 파일이 섞여 있어도 **빠지는 결과 0** — 키워드가 든 줄은 전부 나온다.
- 처음 연결은 친구 폴더 규모에서 **몇 분 안**(규모 확인 후 목표 확정).
- 친구가 "지금보다 낫다"며 계속 쓰는지.

## 9. 친구에게 확인할 것

1. 폴더는 어떻게 쌓이나 — 날짜별 파일? 업체별? 한 파일에 날짜별 탭? 하루에 몇 개 생기나?
2. 파일 수·용량은 — 30일치면 몇 개, 1년치면 몇 개?
3. 무엇으로 찾나 — 상품코드? 송장번호? 주문번호? 업체명? 여러 개를 같이?
4. 반품 정보는 어디서 오나 — 반품 목록도 엑셀인가? 한 번에 여러 건인가? (→ N1 일괄 찾기)
5. 찾아서 알고 싶은 것 — 출고일만? 업체·수량·담당자까지? 찾은 다음에 무엇을 하나?
6. 30일보다 더 거슬러 올라갈 때가 있나?
7. 공유 폴더(NAS)인가, 몇 명이 찾나?
8. 지금 한 번 찾는 데 얼마나 걸리고, 하루에 몇 번 하나?
9. 지금 쓰는 도구는(윈도우 검색, 엑셀 찾기, 다른 프로그램)? 그걸로 부족한 점은?
10. 이게 되면 돈을 낼 만한가 — 얼마 정도면 사겠나?

## 10. 구현 메모 (시제품 기준)

- 지금 `index.html` 안에 [모아보기]와 [폴더 찾아보기] 두 입구. 엑셀 읽기·날짜 판별·색 읽기·저장·암호화는 그대로 재사용.
- 저장 형식은 모아보기와 다르다: 탭마다 자기 제목을 따로 저장.
  - `files`(경로, 크기, 수정 시각, 상태), `sheets`(파일, 탭, 제목 목록, 날짜 칸), `rows`(탭, 엑셀 행, 칸 값 목록, 검색용 글자, 날짜 값)
- 날짜 칸 찾기: 칸 이름(일자·날짜·출고일·발주일 등)과 값 모양(YYYY-MM-DD 비율)으로 탭마다 하나 고름. 못 찾으면 그 탭 결과는 날짜순에서 뒤로.
