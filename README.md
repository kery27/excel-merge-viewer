# 엑셀 모아보기 (시제품)

같은 구조(첫 줄 제목이 같은)의 엑셀·CSV 파일과 탭 여러 개를 끌어다 놓으면, 하나로 모아 바로 검색·필터하는 화면.
서버 없이 브라우저 안에서만 동작하고, 파일은 PC 밖으로 나가지 않는다.

- `index.html` 하나로 완결. 라이브러리는 `vendor/` 로컬 번들(sql.js, SheetJS) — 인터넷 없이, 파일 더블클릭(file://)으로도 열리게.
- 무거운 일(엑셀 읽기·합치기·조회)은 Web Worker 안의 메모리 SQLite에서 한다.
- [가짜 데이터로 체험]: 쇼핑몰 주문 가짜 데이터(탭 하나에 5년치 파일 + 월별 탭 60개 파일)를 실제 xlsx로 만들어 같은 과정으로 읽는다.

## 웹에서 체험

`bash scripts/make-web.sh` → `dist/web/`(웹 페이지용 사본: 바깥 틀 태그를 빼고, SheetJS 번들의 제어 문자를 `\uXXXX`로 바꿈)을 claude.ai 페이지로 올린다. 올린 페이지 안에서는 `alert`/`confirm` 창이 안 뜨므로 알림·확인은 화면 안에서 한다.

## 실측 (가짜 데이터 11칸, 2026-10-29)

| | 10만 건 | 50만 건 |
|---|---|---|
| 파일 2개·탭 62개 읽어서 합치기 | 2.7초 | 15.0초 |
| 검색·필터 | 0.02~0.04초 | 0.13초 |
| 전체 정렬 | — | 0.51초 |

## 셀 색깔 (2026-10-29)

- xlsx·xlsm에서 직접 칠한 **배경색·글자색**을 읽어 표에 원본처럼 칠하고, 칸 제목 옆 **[색]**에서 그 칸에 실제로 쓰인 색(+색 없음)을 체크해 거른다.
- 직접 지정한 색(rgb), 팔레트의 테마색(밝게/어둡게 포함), 옛 색 번호(indexed)를 모두 실제 색으로 바꿔 읽는다. 흰색 채우기·검정 글자는 색 없음으로 본다.
- 제목 줄 색, 값 없이 칠만 남은 칸은 뺀다.
- 못 읽는 것은 요약의 "색 정보 안내"로 알린다: 조건부 서식으로 칠해진 색, 옛 형식(.xls). CSV는 원래 색이 없다.
- 체험용 가짜 데이터에도 색이 있다(배송상태 취소 = 빨간 칸, 반품 = 노란 칸, 금액 50만 원 이상 = 파란 글자).
- 읽는 시간: 같은 컴퓨터(클라우드 개발 환경, 위 표보다 느린 PC)에서 가짜 데이터 50만 건 24.1초 → 27.7초(색칠된 칸 약 18만 개 포함). 색 있는 서식이 없는 파일은 탭을 훑지 않아 거의 그대로.
- 테스트용 색 엑셀: `tests/fixtures/색.xlsx`(`python3 tests/make-color-fixture.py`로 다시 만듦).

## file:// (파일 더블클릭) 확인 — 2026-10-29

Chromium(헤드리스)에서 `index.html`을 서버 없이 직접 열어 확인함: 드래그 앤 드롭·파일 고르기, 칸 순서가 다른 탭 합치기, 제목이 다른 탭·빈 탭 빼고 알리기, 같은 이름 파일 교체, 검색·칸 필터·정렬, 파일별·탭별 보기, 가짜 데이터 체험 모두 정상. 한글·공백이 들어간 폴더 경로도 정상이고, http로 연 것과 읽기 속도 차이 없음. `vendor/` 없이 `index.html`만 열면(압축 파일 안에서 바로 연 경우 등) 안내 문구가 뜨고 체험 버튼이 꺼짐.

다시 확인: `node tests/file-protocol.test.js` (Playwright + Chromium 필요). Windows의 실제 Chrome·Edge에서 더블클릭은 아직 직접 해 보지 않음.
