# 크몽 세팅 상품 초안: 폴더 찾아보기 원격 세팅

_2026-11-12 작성 (가르시아 요청 "크몽 세팅 상품 초안 만들어줘"). **전부 제안이고, 가격은 가설이에요.**_
_크몽 규정은 크몽 공식 안내 두 개로 확인했어요: [용역 서비스 등록 가이드](https://kmong.com/support/expert-center/posts/754)(2026-01-19), [서비스 설명 단계에서 지켜야 할 의무 사항](https://kmong.com/support/expert-center/posts/735)(2024-08-19)._

- **파는 것**: 프로그램이 아니라 **회사 PC에서 실제로 되게 해 주는 세팅 시간**이에요. 프로그램이 무료라는 건 설명에 먼저 밝혀요. 숨기면 크몽 규정 위반이고, 손님이 나중에 알면 나쁜 후기로 돌아와요.
- **손님이 받는 것**: ① 바탕화면 '엑셀 찾기' 아이콘 ② 회사 엑셀을 다 읽어 둔 상태(못 읽은 파일 정리 포함) ③ 직원이 찾는 법. 끝나면 **세팅 결과표**를 보내요(12절). 폴더 연결 자체는 1분이면 끝나서, 그것만 "세팅"이라고 하면 약해요(11/12 가르시아 결정).
- **어필**: "엑셀 검색"이 아니라 **못 찾아서 손해 보던 장면**으로 해요 (hq DECISIONS 11/9).
- **넣는 판**: **폴더 찾아보기만** 넣어요. 새로 만든 부분이라 의뢰인 동의 문제가 없어요. 파일 모아보기 상품(25/45/80만 원)은 그대로 두고, 이 상품은 따로 올려요. 크몽도 복합 서비스는 따로 등록하라고 안내해요.
- **▶ 표시**가 크몽 등록 화면의 칸이에요. `붙여 넣는 글` 상자만 그대로 옮기면 돼요. _기울임 글_은 메모라서 옮기지 않아요.

## 4. ▶ 서비스 설명

`붙여 넣는 글`
```
이런 일, 익숙하신가요?

· 반품이 들어왔는데 언제 어디로 나간 물건인지, 한 달 치 출고 엑셀을 하나씩 열어 송장을 찾는다
· 거래처가 "지난번 그 단가로요" 하는데, 파일을 뒤지다 "확인하고 다시 전화드릴게요" 한다

· 몇 년 전 계약을 찾으려고 연도별 파일, 월별 탭을 열다가 반나절이 간다

엑셀 어딘가에 분명히 있는데 못 찾으면, 확인 못 한 반품을 받아 주거나, 단가를 틀리게 말하거나, 입금이 미수로 남습니다.

회사 PC 바탕화면에 '엑셀 찾기' 아이콘을 만들어 드립니다.
누르면 회사 엑셀 폴더 전체에서 송장번호, 거래처 이름, 금액이 든 줄이 최신 날짜부터 나옵니다.

✔ 파일 이름이 아니라 엑셀 안의 그 줄이 나옵니다. 어느 파일, 어느 탭, 몇 번째 줄인지도 같이 보입니다.
✔ 최신 날짜부터 나오고, 7일·30일·90일·1년 단추로 바로 좁힐 수 있습니다.
✔ (주)·㈜·주식회사, 1,250,000과 1250000처럼 적는 법이 달라도 찾습니다.
✔ 양식을 맞추지 않아도 됩니다. 탭마다 원래 제목 그대로 읽습니다.
✔ 새로 저장한 파일, 고친 파일만 다시 읽어서 금방 반영됩니다.
✔ 엑셀 파일은 그 PC 안에서만 읽습니다. 어디에도 올리지 않고, 저도 파일을 받지 않습니다.
✔ 따로 설치하는 프로그램 없이 크롬, 엣지에서 씁니다.

엑셀 365개, 36만 5천 줄: 처음 읽기 약 12초, 찾기 0.2~0.4초, 다음에 열 때 약 0.3초
PC 성능과 파일에 따라 달라집니다.

[세팅이 끝나면 남는 것]
1. 바탕화면 '엑셀 찾기' 아이콘: 누르면 찾기 창이 바로 열리고, 엑셀을 다시 읽지 않고 바로 찾습니다.
2. 회사 엑셀을 다 읽어 둔 상태: 몇 개 중 몇 개를 읽었는지 알려 드리고, 못 읽은 파일은 이유(암호, 깨진 파일 등)와 처리 방법을 알려 드립니다.

끝나면 이 내용을 '세팅 결과표'로 정리해 크몽 메시지로 보내 드립니다. 결과표에는 개수만 적고, 엑셀 내용은 적지 않습니다.

[세팅 순서]
1. 원격으로 PC에 접속해 크롬·엣지 확인
2. 엑셀 폴더 연결, 건너뛸 파일(백업본 등) 설정
3. 다 읽었는지, 못 읽은 파일이 있는지 확인
4. 자주 찾는 것으로 찾아 보며 최신 날짜부터 맞게 나오는지 확인
5. 저장 위치 설정, 바탕화면 아이콘 만들기
6. 직원과 같이 찾아 보기, 세팅 결과표 보내기

· 프로그램 판매가 아니라 세팅·안내 서비스입니다. 프로그램 사용료는 받지 않고, 세팅하고 확인하고 알려 드리는 시간에 대한 값입니다.

· 한 번에 폴더 1곳(그 아래 폴더 전부 포함)을 찾습니다. 엑셀이 여러 드라이브에 흩어져 있으면 구매 전에 말씀해 주세요.
· 찾아서 보여 주는 기능만 있습니다. 엑셀 내용을 고치거나 합계를 내지는 않습니다.
· 암호가 걸린 엑셀은 읽지 못합니다. 어떤 파일인지 목록으로 알려 드립니다.
· 공유 폴더(NAS)는 DELUXE부터 세팅합니다. 회사마다 환경이 달라서, 세팅 때 연결되는지 먼저 확인합니다.
· 원격은 의뢰인이 보는 앞에서만 하고, 화면은 녹화하거나 저장하지 않습니다.
```

## 5. ▶ 서비스 제공 절차 (진행 순서)

`붙여 넣는 글`
```
1. 구매 전: 크몽 메시지로 세 가지를 알려 주세요. 무엇을 자주 찾는지, 엑셀이 어디에 몇 개쯤 있는지, 세팅할 PC가 몇 대인지. 이 세팅으로 안 되는 경우라면 구매 전에 말씀드립니다.
2. 결제 후 1영업일 안: 원격 날짜와 시간을 정합니다.
3. 원격 세팅: 접속 → 폴더 연결 → 다 읽었는지, 못 읽은 파일 확인 → 자주 찾는 것으로 같이 찾아 보기 → 바탕화면 '엑셀 찾기' 아이콘 만들기
4. 마무리: 세팅 결과표(읽은 엑셀 수, 못 읽은 파일과 처리 방법, 찾기 확인)를 크몽 메시지로 보내 드립니다. DELUXE·PREMIUM은 사용 안내문 1장을 같이 드립니다.
5. 점검: DELUXE는 2주 뒤, PREMIUM은 2주 뒤와 4주 뒤에 원격 30분 (새 파일 반영, 못 읽는 파일, 궁금한 점)
```

## 6. ▶ 작업 전 요청사항 (의뢰인 준비사항)

`붙여 넣는 글`
```

6. 원격 중에 화면에 보이면 안 되는 파일이 있으면 미리 알려 주세요.
```

_크몽은 거래에 필요 없는 개인정보를 묻지 못하게 해요. 위 질문에는 개인정보가 없어요._

## 12. 세팅 결과표 (끝나고 크몽 메시지로 보내는 양식)

```
[세팅 결과] PC 1대 · 2026년 ○월 ○일

· 읽은 엑셀: 352개 중 349개 (줄 21만 개)
· 못 읽은 엑셀 3개: 암호 2개, 깨진 파일 1개
  → 암호 파일: 암호를 풀고 다시 저장하면 읽힙니다. 풀지 말지는 회사에서 정하시면 됩니다.
  → 깨진 파일: 엑셀에서 열어 '다른 이름으로 저장'으로 다시 저장해 주세요.
· 찾기 확인: 송장번호 ○ · 거래처 이름 ○ · 입금액 ○ (최신 날짜부터 나오는 것까지 확인)
· 바탕화면 아이콘: '엑셀 찾기'
· 새 엑셀은 같은 폴더에 저장하시면, 아이콘을 열 때 반영됩니다.
· 문의: ○월 ○일까지 크몽 메시지로
· 다음 점검: ○월 ○일 (DELUXE·PREMIUM)

못 읽은 파일 이름은 찾기 창 위쪽 '파일 ○개 ▾'를 누르면 볼 수 있습니다.
```

- 숫자는 예시예요. 읽은 파일과 못 읽은 파일 수는 찾기 창 위쪽 '파일 N개 ▾'에서, 줄 수는 위쪽 폴더 줄에서 봐요.
- **개수만 적고 파일 이름·엑셀 내용은 적지 않아요.** 크몽 메시지에 손님 정보가 남지 않게 하려는 거예요.
- 보내는 이유: 원격 세팅은 끝나면 한 일이 눈에 안 보여요. 숫자로 남기면 손님은 "내 파일을 다 확인해 줬구나"를 알게 되고, 우리는 파일을 받지 않고도 실제 엑셀에서 어디가 안 되는지 알 수 있어요.
- 채팅에서 예로 든 "날짜 칸이 없는 탭 N개"는 뺐어요. 앱이 그 수를 한꺼번에 세어 주지 않고, 찾기 결과에 탭마다 "날짜 칸 없음"으로만 보여 줘요. 대신 "최신 날짜부터 나오는 것까지 확인"이라고 적어요.

## 13. 올리기 전에 할 것

1. **Windows 실제 크롬·엣지 확인** (가르시아): 폴더 고르기, "방문할 때마다 허용"으로 다시 안 묻는지, 공유 폴더(네트워크 드라이브) 연결을 봐야 해요. **바탕화면 아이콘**도 같이 봐야 해요. 크롬은 '바로가기 만들기'에서 창으로 열기, 엣지는 '앱으로 설치'로 만들고, 아이콘으로 열 때 폴더 허용을 다시 묻는지 확인해요. 지금은 헤드리스 테스트만 했고, 아이콘은 아직 해 보지 않았어요. 돈을 받기 전에 꼭 해야 해요.
2. **크몽용 판** (Claude가 할 수 있음): 폴더 찾아보기만 있고 홈페이지 문의 띠가 없는 판이에요. 주문 뒤 원격으로 넣을 때 써요. 지금 공개 체험판과 오프라인 zip에는 "문의 →" 홈페이지 링크가 있어서, 크몽 손님을 크몽 밖 연락으로 이끄는 것처럼 보일 수 있어요.
3. **원격 프로그램 정하기**: 추천은 크롬 원격 데스크톱이에요. 무료이고, 의뢰인이 알려 준 접속 코드로 한 번 들어가는 방식이에요(의뢰인 PC에 작은 프로그램을 한 번 설치해야 함). 윈도에 들어 있는 '빠른 지원'도 돼요. 팀뷰어·애니데스크 무료판은 개인용이라 돈 받는 일에 쓰면 라이선스 위반이에요.
4. ~~**메인 이미지**~~: 11/12 만듦 (`out/setup-main.png`, 10절)
5. **영상** (Claude가 할 수 있음, 선택): 가짜 회사 폴더 20초 녹화예요.
6. **원격 가능한 요일·시간 정하기**: 배달과 겹치지 않게 정해요. 진행 순서 2번("결제 후 1영업일 안에 일정")을 지킬 수 있어야 해요.

## 14. 가르시아가 정할 것

1. **가격**: 가설은 3.3만 / 15만 / 30만 원이에요. 정하면 hq DECISIONS에 적을게요.
2. **PREMIUM을 둘지**: 크몽에서 패키지를 켜면 3단계로 등록해요. PREMIUM 없이 가려면 패키지를 끄고 한 가지 가격과 추가 가격만 써야 해요. PREMIUM은 팔리기보다 DELUXE를 적당해 보이게 하는 역할이 커요.
3. **환불 약속을 하나 더 넣을지** (제안): "원격 시작 10분 안에 그 PC에서 안 되는 걸로 확인되면 전액 환불." 후기 0건일 때 믿음을 주는 장치예요. 크몽 기본 환불 규정보다 의뢰인에게 유리한 조건이라 넣을 수 있어요(크몽 안내: 따로 정하는 기준은 의뢰인에게 유리하고 지킬 수 있어야 함).
4. **올리는 때**: Windows 확인 뒤가 최소예요. 지난번 추천은 물류 지인이 1주일 실제로 써 보는 게 먼저였어요. 그러면 그 결과를 첫 사례와 설명 문구로 쓸 수 있어요. 심사에 영업일 7일이 걸리니, 등록은 그사이에 해 둬도 돼요.
