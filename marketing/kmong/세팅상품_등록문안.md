# 크몽 세팅 상품 — 등록 문안 (칸별 붙여 넣기용)

_2026-11-13 · 가르시아 요청 "상품 설명 관련 텍스트 양식, 아는 한도 내에서 다". 왜 이렇게 썼는지는 `세팅상품_초안.md`에 있어요._

**쓰는 법**
- 크몽 등록은 PC 웹에서만 돼요 (마이크몽 → 내 서비스 → 서비스 등록하기).
- 아래 상자 안의 글만 그대로 붙여 넣으면 돼요. 상자 밖 글은 메모예요.
- **가격·작업일·환불 문장은 제안값**이에요. 가르시아가 정하면 고쳐요.
- 칸마다 글자 수 제한이 얼마인지는 확인하지 못했어요. 그래서 긴 칸은 **짧은 판**도 같이 적었어요. 화면에서 넘치면 짧은 판을 쓰세요.
- 크몽 화면에 있는데 이 문서에 없는 칸은 맨 아래 "모르는 칸"을 보세요.

## 3. 서비스 설명

```
이런 일, 익숙하신가요?

· 반품이 들어왔는데 언제 어디로 나간 물건인지, 한 달 치 출고 엑셀을 하나씩 열어 송장을 찾는다
· 거래처가 "지난번 그 단가로요" 하는데, 파일을 뒤지다 "확인하고 다시 전화드릴게요" 한다
· 입금자 이름이 잘려 있어서, 어느 거래처 청구인지 엑셀을 넘겨 가며 맞춰 본다
· 몇 년 전 계약을 찾으려고 연도별 파일, 월별 탭을 열다가 반나절이 간다

엑셀 어딘가에 분명히 있는데 못 찾으면, 확인 못 한 반품을 받아 주거나, 단가를 틀리게 말하거나, 입금이 미수로 남습니다.

회사 PC 바탕화면에 '엑셀 찾기' 아이콘을 만들어 드립니다.
누르면 회사 엑셀 폴더 전체에서 송장번호, 거래처 이름, 금액이 든 줄이 최신 날짜부터 나옵니다.

[찾는 방식]
✔ 파일 이름이 아니라 엑셀 안의 그 줄이 나옵니다. 어느 파일, 어느 탭, 몇 번째 줄인지도 같이 보입니다.
✔ 최신 날짜부터 나오고, 7일·30일·90일·1년 단추로 바로 좁힐 수 있습니다.
✔ (주)·㈜·주식회사, 1,250,000과 1250000처럼 적는 법이 달라도 찾습니다.
✔ 양식을 맞추지 않아도 됩니다. 탭마다 원래 제목 그대로 읽습니다.
✔ 새로 저장한 파일, 고친 파일만 다시 읽어서 금방 반영됩니다.
✔ 엑셀 파일은 그 PC 안에서만 읽습니다. 어디에도 올리지 않고, 저도 파일을 받지 않습니다.
✔ 설치 과정이 없습니다. 프로그램 폴더 하나를 PC에 두고 크롬·엣지로 엽니다.

[속도]
엑셀 365개(36만 5천 줄)를 처음 읽는 데 약 12초, 찾는 데 0.2~0.4초였습니다.
가짜 데이터로 개발용 PC에서 잰 값입니다(2026년 11월). PC와 파일에 따라 달라집니다.

[세팅이 끝나면 남는 것]
1. 바탕화면 '엑셀 찾기' 아이콘: 누르면 찾기 창이 열립니다. 읽어 둔 내용이 PC에 저장돼 있어 엑셀을 처음부터 다시 읽지 않습니다.
2. 회사 엑셀을 다 읽어 둔 상태: 몇 개 중 몇 개를 읽었는지 알려 드리고, 못 읽은 파일은 이유(암호, 깨진 파일 등)와 처리 방법을 알려 드립니다.
3. 직원이 찾는 법: 회사에서 실제로 자주 찾는 것 3가지로 같이 찾아 봅니다. DELUXE부터는 모니터 옆에 붙일 안내문 1장을 드립니다.
끝나면 이 내용을 '세팅 결과표'로 정리해 크몽 메시지로 보내 드립니다. 결과표에는 개수만 적고, 엑셀 내용은 적지 않습니다.

[세팅 순서]
1. 원격으로 PC에 접속해 크롬·엣지 확인
2. 프로그램 폴더를 PC에 넣고, 엑셀 폴더 연결, 건너뛸 파일(백업본 등) 설정
3. 다 읽었는지, 못 읽은 파일이 있는지 확인
4. 자주 찾는 것으로 찾아 보며 최신 날짜부터 맞게 나오는지 확인
5. 바탕화면 아이콘 만들기, 닫았다 다시 열어 확인
6. 직원과 같이 찾아 보기, 세팅 결과표 보내기

[구매 전에 꼭 읽어 주세요]
· 프로그램 판매가 아니라 세팅·안내 서비스입니다. 프로그램 사용료는 받지 않고, 세팅하고 확인하고 알려 드리는 시간에 대한 값입니다.
· 윈도 PC의 크롬 또는 엣지가 필요합니다. 휴대폰, 태블릿에서는 폴더 연결이 안 됩니다. 맥은 구매 전에 메시지 주세요.
· 한 번에 폴더 1곳(그 아래 폴더 전부 포함)을 찾습니다. 엑셀이 여러 드라이브에 흩어져 있으면 구매 전에 말씀해 주세요.
· 찾아서 보여 주는 기능만 있습니다. 엑셀 내용을 고치거나 합계를 내지는 않습니다.
· 암호가 걸린 엑셀은 읽지 못합니다. 어떤 파일인지 목록으로 알려 드립니다.
· 브라우저 보안 때문에, 창을 열 때 '폴더 다시 허용' 단추를 한 번 눌러야 할 수 있습니다. 누르기 전에도 지난번에 읽어 둔 내용에서는 찾을 수 있습니다.
· 읽어 둔 내용은 그 PC의 브라우저 저장 공간에 둡니다. 브라우저의 사이트 데이터를 지우면 같이 지워지고, 폴더를 다시 연결하면 다시 읽습니다.
· 공유 폴더(NAS)는 DELUXE부터 세팅합니다. 회사마다 환경이 달라서, 세팅 때 연결되는지 먼저 확인합니다.
· 세팅할 때는 원격 접속 때문에 인터넷이 필요합니다. 세팅이 끝난 뒤에는 인터넷이 없어도 찾을 수 있습니다.
· 원격은 의뢰인이 보는 앞에서만 하고, 화면은 녹화하거나 저장하지 않습니다.
```

_11/12 초안에서 바꾼 곳_
- "따로 설치하는 프로그램 없이" → "설치 과정이 없습니다. 프로그램 폴더 하나를 PC에 두고": 크몽용 판이 PC에 두는 폴더라서요.
- "다음에 열 때 약 0.3초"를 뺐어요. 그 숫자는 웹 주소로 열었을 때 잰 값이고, PC에 둔 파일로 열 때는 재지 않았어요.
- "'폴더 다시 허용' 단추"와 "브라우저 저장 공간" 줄을 넣었어요. 불리한 조건을 숨기면 안 된다는 크몽 규정 때문이에요.
- **Windows에서 직접 확인하기 전에는 올리지 마세요.** 위 글은 개발 환경에서 확인한 동작을 바탕으로 썼어요.

## 4. 서비스 제공 절차 (진행 순서)

```
1. 구매 전: 크몽 메시지로 세 가지를 알려 주세요. 무엇을 자주 찾는지, 엑셀이 어디에 몇 개쯤 있는지, 세팅할 PC가 몇 대인지. 이 세팅으로 안 되는 경우라면 구매 전에 말씀드립니다.
2. 결제 후 1영업일 안: 원격 날짜와 시간을 정합니다.
3. 원격 세팅: 접속 → 프로그램 폴더 넣기 → 엑셀 폴더 연결 → 다 읽었는지, 못 읽은 파일 확인 → 자주 찾는 것으로 같이 찾아 보기 → 바탕화면 '엑셀 찾기' 아이콘 만들기
4. 마무리: 세팅 결과표(읽은 엑셀 수, 못 읽은 파일과 처리 방법, 찾기 확인)를 크몽 메시지로 보내 드립니다. DELUXE·PREMIUM은 사용 안내문 1장을 같이 드립니다.
5. 점검: DELUXE는 2주 뒤, PREMIUM은 2주 뒤와 4주 뒤에 원격 30분 (새 파일 반영, 못 읽는 파일, 궁금한 점). 구매 확정 뒤에도 약속한 날짜에 진행합니다.
```

_칸이 단계별로 나뉘어 있으면 번호마다 한 칸씩 넣으세요._

## 5. 작업 전 요청사항 (의뢰인 준비사항)

```
1. 엑셀 파일은 보내지 마세요. 받지 않습니다.
2. 자주 찾는 것 3가지 (예: 반품 송장번호, 거래처 이름, 입금액)
3. 엑셀이 있는 곳: 내 PC 폴더 / 공유 폴더(NAS) / 둘 다, 대략 몇 개
4. 세팅할 PC 대수, 윈도 10·11 중 무엇인지, 크롬·엣지 중 쓰시는 것
5. 원격 시간에 PC 앞에 계실 분 (원격 접속을 허락해 주셔야 합니다)
6. 원격 중에 화면에 보이면 안 되는 파일이 있으면 미리 알려 주세요.
```

## 6. 수정 및 재진행

```
[제 쪽 원인으로 안 될 때]
세팅한 대로 동작하지 않으면 수정 횟수와 상관없이 다시 접속해 고칩니다.

[무상 수정 (STANDARD 1회, DELUXE 2회, PREMIUM 3회)]
· 의뢰인 사정으로 다시 맞춰야 할 때 씁니다. 예: 엑셀 폴더 위치를 옮겼을 때, 건너뛸 파일을 바꾸고 싶을 때, 바탕화면 아이콘이 지워졌을 때
· 세팅 결과표를 보낸 날부터 STANDARD 7일, DELUXE 14일, PREMIUM 30일 안에 요청해 주세요. 한 번에 원격 30분까지입니다.

[사용법 질문]
같은 기간 동안 크몽 메시지로 답합니다. PREMIUM은 영업일 하루 안에 답합니다.

[유상 (추가 가격)]
· PC 추가, 처음과 다른 PC에 다시 세팅, 기간이 지난 뒤의 요청
· 새 기능 추가나 맞춤 제작은 이 상품에 들어 있지 않습니다.
```

_11/12 초안에서는 "제 쪽 원인도 수정 횟수 안에서"라고 썼는데 고쳤어요. 크몽 안내에 "전문가 귀책 사유로 인한 수정은 반드시 제공해야 하고 무상 수정 횟수에 넣지 않는다"고 되어 있어요._

## 7. 추가 혜택 · 사후 관리

```
· 프로그램 사용료가 없습니다. 세팅 뒤에 매달 내는 돈이 없고, 사용 기간 제한도 없습니다.
· 세팅 결과표를 드립니다. 읽은 엑셀 수, 못 읽은 파일과 처리 방법, 찾기 확인 결과를 적어 드립니다.
· DELUXE는 2주 뒤, PREMIUM은 2주·4주 뒤에 원격 점검(30분)을 합니다. 구매 확정 뒤에도 약속한 날짜에 진행합니다.
```

_크몽은 "100% A/S", "무제한 A/S"처럼 조건 없는 보증을 못 쓰게 해요. 그래서 횟수와 시간을 적었어요._

### (선택) 환불 약속 — 가르시아가 넣기로 하면
```
원격을 시작하고 10분 안에 그 PC에서 동작하지 않는 것으로 확인되면 전액 환불해 드립니다.
```
_후기 0건일 때 믿음을 주는 장치예요. 넣으면 반드시 지켜야 해요. 크몽은 기본 환불 규정보다 의뢰인에게 유리한 조건만 따로 적을 수 있어요._

## 8. 자주 묻는 질문

_크몽은 질문과 답을 따로 넣어요. 하나씩 옮기세요._

**Q1**
```
세팅이 끝나면 무엇이 남나요?
```
```
세 가지입니다. 바탕화면 '엑셀 찾기' 아이콘, 회사 엑셀을 다 읽어 둔 상태(못 읽은 파일 정리 포함), 직원이 찾는 법입니다. 끝나면 세팅 결과표를 크몽 메시지로 보내 드립니다.
```

**Q2**
```
엑셀 파일을 보내야 하나요?
```
```
아니요. 파일은 받지 않습니다. 회사 PC에 원격으로 접속해서 그 자리에서 세팅합니다. 원격 중 화면은 녹화하거나 저장하지 않습니다.
```

**Q3**
```
파일이 인터넷에 올라가나요?
```
```
아니요. 엑셀은 그 PC 안에서만 읽습니다. 찾기용으로 읽어 둔 내용도 그 PC 안에만 둡니다. 세팅이 끝난 뒤에는 인터넷이 없어도 찾을 수 있습니다.
```

**Q4**
```
윈도 탐색기 검색과 뭐가 다른가요?
```
```
탐색기 검색은 그 글자가 든 '파일'을 찾아 줍니다. 이 세팅은 파일 안의 '그 줄'을 날짜순으로 보여 주고, 어느 탭 몇 번째 줄인지 알려 줍니다. 어느 파일인지만 알면 되는 경우라면 탐색기 검색으로 충분할 수 있어서, 구매 전에 말씀드립니다.
```

**Q5**
```
새 엑셀이 계속 생기는데요?
```
```
같은 폴더에 저장하시면 됩니다. 창을 열 때 새 파일과 고친 파일만 다시 읽어서 반영합니다.
```

**Q6**
```
직원 PC 여러 대에서 쓸 수 있나요?
```
```
됩니다. PC마다 한 번씩 세팅해 두면 각 PC가 그 폴더를 읽어 둡니다. STANDARD는 1대, DELUXE는 3대, PREMIUM은 10대이고, 더 필요하면 추가 가격으로 1대씩 더할 수 있습니다.
```

**Q7**
```
암호 걸린 파일은요?
```
```
읽지 못합니다. 어떤 파일인지 목록으로 알려 드립니다. 암호를 풀고 저장하면 읽을 수 있는데, 풀지 말지는 회사에서 정하시면 됩니다.
```

**Q8**
```
엑셀이 아주 많으면요?
```
```
가짜 데이터 365개 파일, 36만 5천 줄로 확인했습니다. 더 많으면 처음 읽는 시간이 늘어납니다. 최근에 고친 파일부터 읽어서, 다 읽기 전에도 최근 것은 찾을 수 있습니다.
```

**Q9**
```
매달 내는 돈이 있나요?
```
```
없습니다. 세팅 비용만 받고, 프로그램 사용료나 기간 제한은 없습니다.
```

**Q10**
```
우리 회사에 맞는 기능을 더 붙일 수 있나요?
```
```
이 상품에는 기능 추가가 들어 있지 않습니다. 찾은 다음에 하는 일(예: 반품 목록을 한 번에 대조)이 필요하면 메시지로 말씀해 주세요.
```

## 12. 주문 전후에 쓰는 크몽 메시지

### 첫 문의 답장
```
안녕하세요, 문의 감사합니다.
맞는 세팅인지 먼저 확인하려고 세 가지만 여쭤볼게요.

1. 주로 무엇을 찾으시나요? (예: 반품 송장번호, 거래처 이름, 입금액) 하루에 몇 번쯤 찾으세요?
2. 엑셀은 어디에 있나요? (내 PC 폴더 / 공유 폴더) 대략 몇 개쯤이고, 몇 분이 찾으세요?
3. 쓰시는 PC는 윈도 10·11 중 무엇이고, 크롬이나 엣지가 있나요?

어느 파일인지만 찾으면 되는 경우라면 윈도 탐색기 검색으로도 충분할 수 있어요. 그런 경우면 구매 전에 말씀드릴게요.
파일은 보내지 않으셔도 됩니다.
```

### 주문 직후
```
구매 감사합니다. 원격 세팅 날짜를 정하려고 해요.

1. 가능한 날짜와 시간을 두세 개 알려 주세요. (STANDARD 40분, DELUXE 2시간, PREMIUM 4시간쯤 걸려요. 나눠서 해도 됩니다)
2. 그 시간에 세팅할 PC 앞에 계실 분이 필요해요. 원격 접속을 허락해 주셔야 합니다.
3. 원격 접속 방법은 날짜가 정해지면 다시 안내드릴게요.

엑셀 파일은 보내지 않으셔도 됩니다. 원격 중에 화면에 보이면 안 되는 파일이 있으면 미리 닫아 주세요.
```

### 세팅 결과표 (작업물로 보내기)
```
[세팅 결과] PC 1대 · 2026년 ○월 ○일

· 읽은 엑셀: 352개 중 349개 (줄 21만 개)
· 못 읽은 엑셀 3개: 암호 2개, 깨진 파일 1개
  → 암호 파일: 암호를 풀고 다시 저장하면 읽힙니다. 풀지 말지는 회사에서 정하시면 됩니다.
  → 깨진 파일: 엑셀에서 열어 '다른 이름으로 저장'으로 다시 저장해 주세요.
· 찾기 확인: 송장번호 ○ · 거래처 이름 ○ · 입금액 ○ (최신 날짜부터 나오는 것까지 확인)
· 바탕화면 아이콘: '엑셀 찾기'
· 새 엑셀은 같은 폴더에 저장하시면, 아이콘을 열 때 반영됩니다.
· 문의: ○월 ○일까지 크몽 메시지로
· 다음 점검: ○월 ○일 (DELUXE·PREMIUM)

못 읽은 파일 이름은 찾기 창 위쪽 '파일 ○개 ▾'를 누르면 볼 수 있습니다.
```
_숫자는 예시예요. 개수만 적고 파일 이름·엑셀 내용은 적지 않아요._

### 점검 안내 (2주 뒤)
```
안녕하세요. 약속드린 점검 날짜가 다가와서 연락드려요.
○월 ○일 ○시에 원격으로 30분쯤 볼게요. 시간이 안 맞으면 편한 시간을 알려 주세요.

점검 때 보는 것
· 새로 생긴 엑셀이 잘 읽히는지
· 못 읽는 파일이 새로 생겼는지
· 찾다가 불편했던 점

그동안 안 찾아지던 것이 있었으면 미리 알려 주세요. 그것부터 볼게요.
```

```
세팅과 점검이 모두 끝났어요. 쓰시다가 궁금한 점은 ○월 ○일까지 크몽 메시지로 물어봐 주세요.
```
