# 원격 세팅 순서 (내가 보는 것)

_크몽 세팅 상품에서 손님 PC를 원격으로 세팅할 때 따라 하는 순서예요. 2026-11-13 작성._
_**Windows에서 아직 직접 해 보지 않았어요.** 헤드리스 크롬(리눅스)에서 파일로 열어 찾기까지는 확인했어요(`tests/kmong-build.test.js`). 0번을 먼저 하고, 다르게 동작하는 곳은 이 문서를 고쳐요._

넣는 판: `bash scripts/make-kmong.sh` → `dist/kmong/엑셀찾기.zip` (어느 판인지는 zip 안 `여는 법.txt` 끝의 버전 줄)

## 0. 올리기 전에 내 Windows PC에서 해 볼 것

zip을 풀고 아래 1~4를 그대로 해 봐요. 되는 것에 표시해요.

- [ ] zip이 한글 폴더 이름(`엑셀찾기`) 그대로 풀린다
- [ ] `index.html`을 크롬으로 열면 처음 화면을 건너뛰고 바로 찾기 화면이 뜬다 (엣지도)
- [ ] [폴더 연결] → 폴더 고르기 창 → 엑셀 몇 개 든 폴더가 읽힌다
- [ ] 창을 닫았다 다시 열면 폴더를 기억한다
  - [ ] "폴더 다시 허용" 단추를 눌러야 하나, 안 눌러도 되나
  - [ ] 크롬이 "방문할 때마다 허용"을 보여 주나 (파일로 연 화면에서도)
  - [ ] 허용하기 전에도 지난번에 읽어 둔 내용에서 찾아진다
- [ ] 바탕화면 아이콘: 4번의 가 방법이 된다 / 안 되면 나 방법이 된다
- [ ] 아이콘으로 연 창에서도 폴더를 똑같이 기억한다
- [ ] 아이콘 그림이 `엑셀찾기.ico`로 바뀐다
- [ ] 공유 폴더(네트워크 드라이브, 예: Z:)가 연결된다 — DELUXE 조건
- [ ] 암호 걸린 엑셀, 깨진 파일이 "못 읽은 파일"에 뜬다
- [ ] 크롬 '인터넷 사용 기록 삭제'로 사이트 데이터를 지우면 읽어 둔 내용이 지워지고, 다시 연결하면 읽힌다

결과는 README "폴더 찾아보기" 끝의 "Windows 크롬에서 아직 확인 못 함" 줄과 hq에 적어요.
"폴더 다시 허용"이 매번 필요하면 등록 문안 3절의 그 줄은 그대로 두고, 필요 없으면 지워요.

## 1. 프로그램 폴더 넣기

1. 주문 뒤 크몽 메시지에 `엑셀찾기.zip`을 첨부해 보내요.
2. 손님 PC에서 내려받아 `C:\엑셀찾기`에 풀어요.
   - zip 안에서 바로 열면 안 돼요 (vendor 폴더를 못 찾아요).
   - 손님이 지우지 않을 곳에 둬요. 바탕화면·다운로드 폴더는 피해요.
3. `C:\엑셀찾기\index.html`을 크롬으로 열어요 (우클릭 → 연결 프로그램 → Chrome). 크롬이 없으면 엣지로 해요.

## 2. 엑셀 폴더 연결

1. [폴더 연결] → 엑셀이 모인 폴더 고르기 → 허용.
2. 읽기가 끝나면 위쪽 "파일 ○개 ▾"를 눌러 못 읽은 파일과 "확인할 것"을 봐요.
3. [설정]에서 손님과 정해요.
   - 건너뛸 파일: 백업·복사본처럼 이름에 들어가는 글자
   - 파일 크기 상한
   - 띄어쓰기를 무시하고 찾을지 (기본은 끔)
4. 저장 위치는 기본(브라우저 안)으로 둬요. 손님이 브라우저 기록을 자주 지우면 '내가 고른 폴더'로 바꿔요.

## 3. 같이 찾아 보기

- 손님이 말한 3가지를 **손님이 직접** 쳐 보게 해요.
- 볼 것: 최신 날짜부터 나오는지, 기간 단추(7일·30일·90일·1년), 줄을 누르면 나오는 출처(파일 › 탭 · 행)와 [위치 복사].
- 여러 말이 모두 든 줄은 `+`로 이어 써요 (예: `테스트상사+P0123`).
- 연습은 [← 처음 화면] → [가짜 회사 폴더로 해 보기]로 해요.

## 4. 바탕화면 '엑셀 찾기' 아이콘

**가. 크롬 메뉴로**
⋮ → 전송, 저장, 공유 → 바로가기 만들기 → 이름 `엑셀 찾기` → '창으로 열기' 체크 → 만들기
(엣지: … → 앱 → 이 사이트를 앱으로 설치)

**나. 손으로** (가 방법이 파일로 연 화면에서 안 될 때)
1. 바탕화면 빈 곳 우클릭 → 새로 만들기 → 바로 가기
2. 항목 위치에 아래 한 줄을 붙여 넣기
   - 크롬: `"C:\Program Files\Google\Chrome\Application\chrome.exe" --app="file:///C:/엑셀찾기/index.html"`
   - 크롬이 사용자 폴더에 깔린 PC: `"%LOCALAPPDATA%\Google\Chrome\Application\chrome.exe" --app="file:///C:/엑셀찾기/index.html"`
   - 엣지: `"C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe" --app="file:///C:/엑셀찾기/index.html"`
3. 이름 `엑셀 찾기`
4. 만든 아이콘 우클릭 → 속성 → 아이콘 변경 → `C:\엑셀찾기\엑셀찾기.ico`

만든 뒤에는 창을 모두 닫고, 아이콘으로 다시 열어 찾아지는지 확인해요.

## 5. 세팅 결과표 보내기

- 양식은 `세팅상품_등록문안.md` 12절이에요.
- 숫자는 찾기 창에서 봐요: 읽은 파일·못 읽은 파일 수는 "파일 ○개 ▾", 줄 수는 위쪽 폴더 줄.
- 개수만 적어요. 파일 이름과 엑셀 내용은 적지 않아요.
- DELUXE·PREMIUM은 사용 안내문 1장(그 회사가 찾는 3가지로)과 점검 날짜를 같이 보내요.

## 6. 지킬 것

- 엑셀 파일을 내 PC로 가져오지 않아요. 원격 화면을 녹화하거나 캡처하지 않아요.
- 손님 엑셀의 내용을 크몽 메시지, hq, 저장소에 적지 않아요.
- 크몽 밖 연락처는 먼저 건네지 않아요. 작업에 꼭 필요할 때만 주문 뒤에 나눠요.
- 원격은 손님이 보는 앞에서만 하고, 끝나면 접속을 끊은 것을 같이 확인해요.

## 7. 아직 정하지 않은 것

- **원격 프로그램**: 후보는 윈도에 들어 있는 '빠른 지원'(손님 쪽 설치 없음, 돕는 쪽은 마이크로소프트 계정 필요 — 직접 확인 필요)과 크롬 원격 데스크톱(무료, 손님 PC에 설치 필요). 팀뷰어·애니데스크 무료판은 개인용이라 쓰지 않아요.
- **웹 주소판을 같이 둘지**: 파일로 연 화면에서 "폴더 다시 허용"이 매번 필요하면, 문의 띠 없는 판을 웹 주소로도 두는 길이 있어요(웹 주소에서는 "방문할 때마다 허용"이 됨). 공개 사이트에 새 주소가 생기는 일이라 가르시아 결정이 필요해요.
